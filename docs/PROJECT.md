# Proyecto: Sitio Web de Pastelería (Nombre provisional: Lila's Cakes)

## Visión
Crear un sitio web atractivo, cálido y profesional para una pastelería artesanal. El sitio debe transmitir el estilo "Editorial Cálido" y "Retro-Chic". El cliente (dueño de la pastelería) es ambiguo, por lo que el diseño debe ser modular y fácil de modificar.

## Público Objetivo
Todos, pero el sistema debe permitir clasificar el catálogo por públicos (ej. "Para bodas", "Para niños", "Veganos").

## Funcionalidades Clave (MVP)
1. Página de inicio informativa con Hero section.
2. Catálogo de productos (fotos y precios) con categorías dinámicas.
3. Formulario de contacto/pedido.
4. Soporte para Modo Claro/Oscuro.
5. Soporte multidioma (Español e Inglés).

## Diseño
- **Colores:** Rosa suave (fondo), Rosa intenso (acentos), Marrón chocolate (texto).
- **Tipografías:** Montserrat (cuerpo) y Caveat (logo/títulos).
- **Estilo:** Limpio, con mucho espacio en blanco, bordes redondeados, imágenes grandes.

## Futuro (No en este MVP)
- Base de datos PostgreSQL/Supabase.
- Pasarela de pagos (E-commerce).
- Blog de recetas.
